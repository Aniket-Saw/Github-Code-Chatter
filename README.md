# 💻 GitHub Code Chatter (RAG System)

A Retrieval-Augmented Generation (RAG) system that allows developers to perform natural language Q&A over public GitHub codebases. Built with AST-aware language chunking, vector retrieval, and Large Language Models.

---

## 🛠️ Tech Stack
* **Frontend / UI:** Streamlit
* **LLM Framework:** LangChain / LlamaIndex
* **Embeddings:** OpenAI / Hugging Face Embeddings
* **Vector Database:** ChromaDB / FAISS
* **Code Parsing:** Tree-Sitter / Language-Aware AST Splitters

---
